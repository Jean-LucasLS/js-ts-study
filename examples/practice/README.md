# Practical Examples

Runnable examples grouped to match the short study modules. Run commands from the workspace root.

## Order

1. [Basic](basic/) - [string operations](basic/variables/string-operations.js), [conditional branches](basic/conditionals/time-of-day.js)
2. [Functions](functions/) - [callbacks and closures](functions/callbacks-and-closures.js), [composition and partial application](functions/composition.js), [validation and price formatting](functions/price-summary.js)
3. [Arrays](arrays/) - [transformations and sorting](arrays/transform-and-sort.js)
4. [Objects](objects/) - [factory objects, `this`, and closures](objects/factory-and-this.js)
5. [Classes and `this`](classes/) - [objects returned from constructors](classes/constructor-return.js); the browser-based [people form](../browser/people_class/people.html) keeps its JavaScript and styles beside its HTML.

Run an individual Node.js example, for example:

```powershell
node examples/practice/functions/callbacks-and-closures.js
```
